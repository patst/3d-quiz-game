# 3d-quiz-game

An educational 3D maze game in the browser for German-speaking children (5–7 years).
Children explore comic-style mazes and solve small math and German challenges to earn
rewards for their avatar.

**Status:** v1 feature-complete (M1–M7): mazes with treasure chests (6 math + 4 German challenge types, adaptive difficulty), cheerful German voice, star jar rewards, animal friends, parents area, installable offline PWA. Next: playtest ([checklist](docs/playtests/README.md)).

Play: https://patst.github.io/3d-quiz-game/

```bash
npm ci && npm run dev
```

# Roadmap

**Status:** DRAFT — proposal. Principle: ship a playable vertical slice early and test it
with a real child before building breadth.

| Milestone | Goal | Done when |
|---|---|---|
| **M0 Design & architecture** | Owner approves game-design + architecture + ADRs 0002–0004 | statuses = APPROVED / Accepted |
| **M1 Tech spike** | Project skeleton, CI, deploy to GitHub Pages. Procedural maze rendered in toon style, avatar walks by tap/keys on phone + desktop | Playable URL on a phone at 30+ fps |
| **M2 Vertical slice** | 1 world, 1 maze with 3 stations, 2 challenge types (Mengen zählen, Anlaut finden), audio, stars | **Playtest with a 5–7 year old**; findings written to `docs/playtests/` |
| **M3 Rewards & profile** | Avatar items, inventory, save/load, child profiles, parent gate | Progress survives reload |
| **M4 Adaptive difficulty** | Skill model, levels per challenge, bronze/silver/gold chests | Unit-tested skill model; second playtest |
| **M5 Content breadth** | Full initial challenge catalogue, word bank ≥ 150 words, 2nd world | — |
| **M6 Polish & PWA** | Offline install, parents area stats, performance pass | Lighthouse PWA pass, works offline |
